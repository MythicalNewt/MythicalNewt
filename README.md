# Shreyas Cheruku — Engineering Portfolio

Personal portfolio highlighting my work in embedded systems, firmware, hardware design, and rocketry.

**Live site:** https://mythicalnewt.github.io/MythicalNewt/

## Featured projects

- **VADA Avionics** — rocket flight-computer work spanning PCB design, firmware, sensor integration, telemetry, and data logging.
- **Project Skywalker** — high-powered rocketry project using simulation, CAD, and onboard electronics.
- **Mars Communication Mesh** — second-place Hardware Hackathon 2.0 team project; my contribution included a discrete H-bridge driver for a custom-PCB magnetorquer and a MicroPython demo.

## Built with

- HTML, CSS, and vanilla JavaScript
- Responsive layout and accessible navigation
- GitHub Actions deployment to GitHub Pages

## Local preview

Open `index.html` in a browser. No build step or package installation is required.

Project details and media will be expanded as additional schematics, test documentation, and video assets are ready.
